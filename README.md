## Movie Recommendation System

A **Content-Based Movie Recommendation System** developed using **Python, Streamlit, Pandas, and Scikit-learn**. The application recommends movies based on the similarity of their genres and plot overviews by converting text into numerical vectors using **CountVectorizer** and retrieving the most similar movies using **K-Nearest Neighbors (KNN)** with **Cosine Similarity**.

## Features

- Interactive Streamlit web application
- Content-based movie recommendations
- Movie title search with spelling correction using `difflib`
- Text vectorization using **CountVectorizer**
- K-Nearest Neighbors (KNN) with **Cosine Similarity**
- Displays the top recommended movies for the selected title

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Pickle

## Workflow

1. Load the movie dataset.
2. Preprocess the data by combining genres and plot overviews into a single **tags** feature.
3. Convert the text into numerical vectors using **CountVectorizer**.
4. Train a **K-Nearest Neighbors (KNN)** model using **Cosine Similarity**.
5. Accept a movie title from the user through the Streamlit interface.
6. Use `difflib` to suggest the closest matching title if the entered name is misspelled.
7. Display the most similar movie recommendations.
